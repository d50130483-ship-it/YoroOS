# YoroOS 0.1 «Astra»

Собственная 32-битная операционная система для x86: своё ядро (YoroKernel),
свой загрузчик (YoroBoot, без GRUB), собственный графический интерфейс,
файловая система, оконный менеджер и приложения.

## Что умеет версия 0.1

* **Установщик** — записывает загрузчик и ядро на реальный ATA-диск
  (MBR + stage2 + ядро), после чего машина загружается прямо с диска.
* **Рабочий стол** с обоями, иконками, панелью задач и **меню Пуск**.
* **5 приложений-«китов»**:
  * Проводник (своя файловая система YoroFS),
  * Терминал (YoroOS Shell: `dir`, `cd`, `type`, `sysinfo`, `neofetch`, …),
  * Параметры YoroOS (темы, обои, система, о системе),
  * YoroNet — браузер со стартовой страницей и тремя страницами загрузки
    (Chrome, Firefox, Matronix),
  * «Магазин Yoro» — установка приложений с иконками.
* **ZIP-архивы**: просмотр содержимого и распаковка (собственный DEFLATE-декодер).
* **EXE**: разбор структуры MZ/PE (машина, число секций, точка входа, подсистема).
* Блокнот, калькулятор, просмотр изображений, «О системе», корзина,
  горячие клавиши (Ctrl+Alt+T — терминал, F10 — магазин, Ctrl+Alt+L — раскладка).

## Сборка

```
make            # build/kernel.bin, build/yoroos.img, build/yoroos.iso
```

Нужны только `gcc`, `binutils`, `python3`. Ядро линкуется как 32-битный ELF,
образ собирается скриптами из `tools/`.

## Запуск

```
qemu-system-i386 -cdrom build/yoroos.iso -m 256 -drive file=disk.img,format=raw
```

или

```
qemu-system-i386 -cdrom build/yoroos.iso -m 256 -hda disk.img
```

Без `-hda` система работает в live-режиме, установщик сообщит, что диска нет.

## Установка на диск

1. Загрузитесь с ISO.
2. На рабочем столе (или в меню Пуск) откройте **«Установить YoroOS»**.
3. Выберите язык, диск, имя пользователя и параметры, нажмите **«Установить»**.
4. Установщик запишет MBR, вторую стадию загрузчика и ядро YoroKernel,
   проверит запись и предложит перезагрузиться.

Внимание: данные на выбранном диске перезаписываются.

## Структура

```
boot/     загрузчик: boot.asm (MBR), stage2.asm (VBE, A20, загрузка ядра)
kernel/   ядро: старт, GDT/IDT, драйверы, графика, шрифт, ФС, WM, приложения
include/  общий заголовок kernel.h
tools/    mkimage.py, mkiso.py, mkfont.py
docs/     README-ISO.txt
```
